stepsSummary (src/control/dashboard.ts:1726) folds a run of tool calls into one line. For each call it looks up the tool in toolLooks (:1653), which gives an action (read, command, change, search, subagent and so on) and the argument naming the file. Calls are grouped by action. A file counts once however often it's touched, so an edit and a write to one path make one changed file. A tool with no look becomes its own action, named as it is. Actions are sorted by priority, and the first phrasesShown (3) are phrased, like "Ran 2 commands, read 2 files". Whatever is left collapses into "used another tool" or "used N other tools".
