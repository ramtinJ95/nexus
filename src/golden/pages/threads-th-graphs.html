Repository

Threads clone the repository at this branch, or in a scratch project start an empty repository on it, and boot on this node unless they pick another. With auto, each boots on the node with the most room left among those that hold the image and the project's secrets. A scratch pylon keeps nothing once its thread is deleted, so its agent publishes what is worth keeping. GitHub access sends the node's GH_TOKEN to api.github.com and github.com, so agents can create repositories and push. Each pylon gets 2 CPUs, 4 GiB of memory and 10 GiB of disk. nexus project add can set those, allowed hosts, logins and other secrets.
